# HoloLens 电脑端控制

用 USB 把 HoloLens 接到电脑，就能在电脑上看画面、点按操作；人不在时，眼镜睡了也会自动叫醒。稻视界（水稻采集与识别）是这套平台上的验证应用。

## 现在可以

- 接上 USB 自动连接，断线自动重连
- 电脑上实时看画面、点按、开关应用
- 无人值守时自动唤醒

## 接下来

- 画面更流畅
- 把静态、动态识别模型放进眼镜
- 接入前后端
