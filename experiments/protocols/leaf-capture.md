# 叶片采集与光照对照协议

适用议题：EXP-LEAF-001、EXP-LIGHT-001。目标是判断取景、曝光、稳定性检查和裁剪是否保留可用于识别的叶片信息。

## 样本与准备

使用真实水稻叶片，记录批次、样本编号和人工观察。类别不明确时标为“待标注”，不能用模型输出充当真值。普通场景与非叶片分别作为对照。屏幕翻拍和离线调亮/调暗可以用于程序测试，不能替代本协议。

核对应用版本、相机预览与识别服务。确定叶片能完整落入目标区域，记录取景距离、背景和遮挡。原图、裁剪图与返回结果保持同一采集身份。

## 条件矩阵

| 条件 | 观察重点 |
| --- | --- |
| 普通光 | 叶片完整性、纹理与对焦 |
| 强光 | 高光饱和、纹理丢失与曝光反馈 |
| 暗光 | 噪声、清晰度、曝光与稳定等待 |
| 混合光 | 同片叶子明暗分布与局部细节 |

尽量保持同片叶子、视角与距离一致。各条件的实际样本数与重复次数写入报告，采样不足时保留结论范围。

## 每个样本保留的材料

- 应用版本、批次、叶片编号与光照条件。
- 原图和裁剪图的受控资料引用、尺寸、字节数和 SHA256。
- 目标区域、曝光补偿 EV、清晰度与亮暗饱和比例。
- 上传请求与返回结果的绑定校验、模型结果与人工观察。
- 失败或拒识原因；取消、模糊和过曝时是否保持取景且没有上传旧图。

源图像可能包含环境信息，先检查后共享。项目仓库登记脱敏摘要与批次引用，原件放项目组约定的资料位置。

## 判读

分别判断叶片是否完整入框、纹理是否可辨、曝光反馈是否改善实际成像，以及请求/结果是否对应。高置信度不自动视为正确识别，单张成功不推广到全部条件。质量阈值需要随独立样本评估，不能仅凭接口支持或调用成功判定效果。
