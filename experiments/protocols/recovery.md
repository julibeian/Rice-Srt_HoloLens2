# 启动、网络与低功耗恢复协议

适用议题：EXP-RECOVERY-001。目标是验证同一版本在启动、网络波动与电源状态变化后的实际可用性。

## 用例

| 用例 | 操作与检查 |
| --- | --- |
| 冷启动 | 读取安装与实际运行版本，取得新会话、相机预览和有效界面 |
| 网络中断 | 保留待传照片，恢复后复用原请求编号，不重拍或借用新位置 |
| Wi-Fi 断开 | 核对既有配置与同适配器无线电，仅在策略允许时恢复 |
| 低功耗与休眠恢复 | 分别读取电源状态和运行证据，查看有效全息画面 |
| 重启后恢复 | 核对身份、应用版本、历史与待传任务，再完成一次采集 |

安装成功、激活被接受、HTTP 200 和进程存在分别记录其含义，最终仍需有效应用事件与画面。Wi-Fi 连通不自动等于云服务可达。

## 结果

报告记录环境条件、版本、用例、错误码、恢复是否成功及证据引用。设备不可达或状态未知时保留未知，不据旧结果填写当前通过。

控制实验结束后确认自身流关闭、租约恢复默认模式和临时诊断设置还原。原始详细运行日志由执行环境保存，团队结论按用例与版本归纳。
