# 实验中心

实验按问题、编号和应用版本组织。每份报告说明样本、条件、方法、结果和限制，便于其他成员复核与补充。

新增实验先提交“实验记录”Issue，选择或补充协议，再按 [报告模板](templates/report.md) 保存结论。样本编号与字段见 [数据规范](../data/README.md)。

已有单场景结论保留其适用范围。需要查看像素或复核操作时应取得原始资料；源码库中的结果摘要不替代原件。实验报告围绕版本、条件与批次更新。
