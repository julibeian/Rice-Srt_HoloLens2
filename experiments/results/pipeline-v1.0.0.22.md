# v1.0.0.22 采集链路验证摘要

实验编号：EXP-CAPTURE-001。使用 HoloLens 2，在单一室内场景采集一个非叶片对照。此项验证采集与结果关联，不评估叶片病害识别准确率。

## 方法与结果

使用原始 PV 预览，移动目标框后点按快门。保存高清原图，进行质量检查与裁剪，上传到既有识别服务，核对返回并写入历史。

## 可支持的结论

该版本在此场景完成了新拍、裁剪、上传、返回和保存，非叶片样本按拒识展示。两项可见操作通过后，不能推广到全部应用或系统控件。

## 限制与后续

样本数为 1，且不是水稻叶片。亮度统计只描述这张图，不能推出多光照效果、色彩正确性或病害细节保留。真实叶片、独立标注、不同光照与长期运行继续按照相应协议验证。

另有稳定性观察出现过服务请求 Win32 12007、低功耗下未取得有效运行/全息帧等情况。它们列入 EXP-RECOVERY-001，不能把本次成功当作设备在其他状态下始终可用。
