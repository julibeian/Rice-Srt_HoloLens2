# 共用界面构建输入

这里固定眼镜构建器使用的 83 个共用界面、业务和资源文件，以及第三方说明和图片来源记录。[SOURCE.json](SOURCE.json) 保存每个文件的字节数与 SHA256，便于独立构建与审阅更新。

眼镜平台适配位于 `apps/field-app/src/`。更新本快照时同步来源清单，并检查生成结果和相应测试；需要临时使用另一份源码可显式设置 `RICE_MINIPROGRAM_ROOT`。

水稻示例图片的权利与来源见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) 和 [图片来源](docs/symptom-photo-sources.json)。示例资源不作为真实叶片采集实验结果。原来源说明中的完整 `_archive/` 档案不包含在本快照中。
