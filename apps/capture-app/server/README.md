# 原型识别网关

网关在服务器回环地址提供 `/hololens/` 接口，把授权图像转给现有识别后端。它不加载或更换模型。当前独立应用网关见 `apps/field-app/server/`。

## 请求约束

使用 `X-HoloLens-Token` 与 `X-HoloLens-Run` 校验任务会话；照片携带 `X-Request-ID`。预测接口只接受一个受限大小的图像文件，返回照片 SHA256、请求编号和识别编号。客户端核对后才展示结果。

相同请求与同一图像重试复用结果；相同编号换图拒绝处理。忙碌状态有界拒绝，不建立无限队列。拒识是模型判定，不能当作网络故障或健康结果。

事件接口只保留批准的少量字段；令牌、照片字节与环境配置不进入事件正文。证据与图片读取受会话权限控制。

## 验证与部署

在仓库根目录运行 `python -B -m unittest discover -s apps/capture-app/server -p 'test_*.py'`。测试使用回环推理替身，覆盖转发、哈希绑定、会话、幂等、忙碌、失败与私有文件隔离。

`deploy.sh`、服务单元和 Nginx 片段为服务器维护材料，实际部署前核对目标服务与配置。仓库文档更新不会自动执行部署。
