# 采集原型与复用工具

本目录保存单张采集原型：眼镜原生工具拍照，PC 通过已配对 USB 取回图像，经网关识别后核对结果并写回设备。当前产品路径见 [apps/field-app](../../apps/field-app/README.md)。

| 路径 | 用途 |
| --- | --- |
| `device-research/` | WinRT 相机、网络、URI 与传输辅助工具 |
| `uwp/` | 原型采集与结果面板 |
| `web/` | 备用浏览器客户端与协议实现 |
| `server/` | 原型隔离网关 |
| `ops/` | 单次采集、传输与测量工具 |

其中网络与 URI 工具仍被当前应用构建复用，修改前先检查引用。原型已验证过非叶片采集与匹配结果回传，但不能代替当前应用的真实叶片、可见界面或完整时延实验。

恢复已存在的任务时复用同一照片与请求身份，避免重复曝光。性能实验应按阶段分别记录相机、USB、网络、推理与显示，不将某段传输/恢复耗时作为整机拍照到显示耗时。

离线测试命令见 [开发指南](../../docs/development.md)。新增原型结论使用 [实验报告模板](../../experiments/templates/report.md)，不要把原始执行日志直接作为版本说明。
