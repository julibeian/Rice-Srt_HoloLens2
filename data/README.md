# 样本与资料规范

采集数据按批次与样本编号组织。源码仓库保存规范、模板和脱敏摘要；原图、裁剪图和大文件放项目组约定的共享资料位置，并登记可复核的引用。

建议编号：批次 `BATCH-001`，叶片 `LEAF-001`，同片叶子的图像 `IMAGE-001`。编号用于关联，避免把个人日程或机器路径编码进样本名。

使用 [sample-template.json](templates/sample-template.json) 记录版本、实验编号、光照、人工标注、原图/裁剪引用、哈希与结果。模板字段是待填内容，不代表已经采集样本。

人工标签与模型输出分别保存。训练、验证、测试划分时避免同片叶子或同批高度相似图像跨集合。记录来源、许可和处理方法，避免无法追溯的数据混入评估。

上传前检查人像、室内环境和位置等信息。访问令牌、设备账户、网络配置和原始诊断不写入资料引用。原始技术日志可随受控实验资料保留，团队报告只保留判读需要的信息。
