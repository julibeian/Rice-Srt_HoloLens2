# 第一阶段验证范围与复现记录

整理日期：2026-10-25。此页区分历史真机结果、本次发布检查与新环境应完成的验收。它不证明读者的设备当前在线。

## 已有历史真机记录

| 项目 | 已观察结果 | 边界 |
| --- | --- | --- |
| 开发配对复用 | 新进程、后续 SSH 会话无需重新输入开发配对码 | 单个 Windows 用户与已配对目标 |
| 身份与受限管理 | 原 SSH 指纹、设备只读命令、目录操作、文件往返哈希已核对 | 无管理员权限，不是远程 PowerShell |
| GUID 变化 | 旧 GUID 不阻止发现原设备；错误指纹仍被拒绝 | GUID、名称、地址不取代 SSH 身份 |
| SSH 会话重连 | 25 日连续两次约 4.4 秒恢复，随后实际命令成功 | 不是线缆实际拔插试验 |
| 卡住桥恢复 | 25 日冻结桥进程后约 131 秒自动恢复原目标 | 恢复预算与现场条件相关，不是保证时限 |
| 真实设备重启 | 25 日单次重启后约 68 秒 USB 恢复，运行时长归零、原 SSH 指纹及只读命令通过 | 不以重启接口接受作为完成依据；没有再次重启复验 |
| 短时无输入观察 | 约 200 秒、14 个状态样本保持，之后命令仍成功 | 30 分钟、跨天和多轮休眠观察未完成 |

原设备曾调整已有网络自动连接和接电电源设置，并保存原值。因此恢复结果包含这些条件，不能外推成所有设备的默认效果。没有完成实际 USB 拔插、Windows 注销再登录或 IPv6 自动备用管理通道验收。

## 本分支的发布检查

2026-10-25 在现有 Windows 开发环境重新执行工作站前置检查及四组连接回归，全部通过。身份辅助脚本只做源码与解析检查，未据此新增真机通过结论；新电脑须按下一节保留自己的结果。
