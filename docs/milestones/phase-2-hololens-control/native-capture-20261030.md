## 新采集组件

1.0.0.1 把 WGC 调用移入本项目的原生 WinRT DLL，以字符串状态接口连接 JavaScript。新包不再携带 Win2D 或 VCLibs 依赖，构建使用已有 Windows SDK、Zig 和链接器。

应用启动只做能力与图形设备检查。点击测试按钮后才调用系统来源选择器，等待选择最多 120 秒；取得来源后的采样预算为 20 秒。原生组件保存逐帧单调接收时间与设备时间戳，关闭各帧、采集会话和帧池，另保存一张 BMP。GPU 读回使用非阻塞 Map；读回失败保留 HRESULT，不伪造验证图。

前端排除前三秒、重复或回退的设备时间戳，按实际接收时间统计。采集或关闭失败时不报告成功帧率；设备采集帧率与电脑传输／绘制帧率明确区分，图像内容和整机范围仍需真机视觉核对。该包仅声明 `graphicsCapture`，没有网络、相机或麦克风能力，没有输入接口。

本机验证范围：

- ARM64 DLL 以警告视为错误构建通过，PE 为 ARM64／App Container；Appx 清单验证通过，WinRT 元数据成功生成四个接口方法的投影。
- 同源 x64 DLL 在本机实际加载，28 个 ABI 断言通过，包括激活、接口查询、状态读取、无效路径拒绝与停止；图形设备及帧池工厂为 ready。没有打开选择器、创建采集会话或操作电脑窗口。
- 12 项前端／统计检查通过，覆盖不自动采集、重复点击拒绝、原生失败、关闭失败、状态丢失、退出和时间戳计数。
- PowerShell 语法检查通过。上述检查不证明眼镜上的 JavaScript 投影、来源选择、实际采集、帧率或资源回收已经通过。
