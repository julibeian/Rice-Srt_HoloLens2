# HoloLens 整机操作与管理

二阶段范围包括系统界面、跨应用、中英文输入、二维与三维交互、应用与文件管理、设备诊断和异常恢复。稻视界作为其中一个验证应用，现有专用手册继续保留其原验收边界。

实施入口为 [执行入口](../../plans/20261027-phase2-hololens-control/执行入口.md)，任务和真机验收分别登记在 [任务状态](../../plans/20261027-phase2-hololens-control/任务状态.json)。只有全部 P0、P1 和必备验收完成，才宣布二阶段完成。

当前已完成 M0 的源码基线、环境清单和能力登记，T05 已选定官方 SDK 自制适配器作为主输入路线。T06 通用应用模型与 T07 延迟修复已有代码及真机证据，完整通用交互和第二台电脑复现仍未完成；观察状态按具体时间记录。
