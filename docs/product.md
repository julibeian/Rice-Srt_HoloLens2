# 产品说明

稻视界 HoloLens 实验平台用于研究眼镜端水稻图像采集、图像质量控制与识别结果核查。平台将相机采集和界面放在眼镜上，识别服务放在云端，支持项目组围绕同一版本开展对照实验。

## 使用流程

打开应用后进入相机预览，选择目标区域与取景范围。拍照时等待画面稳定，检查高清图像质量，再裁剪并上传目标区域。结果页面可以核对识别区域、查看原图、返回取景和查阅历史。

照片位置可由系统提供或补充标记；位置不可用时仍可识别。失败上传保留原请求身份，恢复后继续发送同一任务。

## 产品组成

| 组成 | 职责 |
| --- | --- |
| 眼镜应用 | 原始预览、曝光与对焦、拍照、裁剪、上传、结果与历史 |
| 识别网关 | 设备会话、请求约束、图像哈希绑定与结果返回 |
| 设备实验工具 | 部署诊断、全息画面与受保护输入 |
| 实验与资料中心 | 采样规范、对照结果、文献与技术资料 |

## 当前边界

取景区域由使用者指定，未提供已验证的自动叶片分割。现有拒识对照只能说明该次处理链路，不能推出病害准确率。真实叶片、多光照、网络波动、跨休眠与重启仍需实验。具体状态见 [实验结果](../experiments/results/pipeline-v1.0.0.22.md)。

现有云端模型继续作为识别后端；模型训练、权重变更与数据集评估应作为独立研究议题记录。
