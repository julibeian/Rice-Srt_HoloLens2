# HoloLens 二阶段执行入口

本目录是后续代理接续二阶段工作的入口。阶段目标为整台 HoloLens 的电脑端可视化操作与管理，覆盖系统界面、跨应用操作、中英文输入、二维与三维交互、设备维护和异常恢复。稻视界是测试应用之一。

## 先读与状态维护

1. 读取项目根 AGENTS.md，保留已有设备身份、认证和控制恢复要求。
2. 读取本文件与同目录 `任务状态.json`，确定下一个任务和依赖。任务、需求和验收的当前状态以 JSON 为准。
3. 按任务需要读取 [详细规划](二阶段整机控制规划书.md) 对应章节，避免每次重读全部报告。
4. 实施前核对当前源码改动、设备可达性和所需依赖；历史在线记录不能代表当前在线。
5. 完成任务后同步 JSON 的任务状态、需求覆盖、验收结论和证据引用，再更新本文件的当前检查点。

规划创建于 2026 年 10 月 27 日。M0 的 T01 至 T03 已实施：源码与历史证据冻结、当前设备与电脑环境核对、16 项能力登记和统一结果格式。通用交互仍待 M1 验证；已有真机成果保留在基线材料中，不重复计为本规划新增完成项。

## 执行约定

P0 是优先前置能力，P1 是整体验收必备能力，两者都必须完成。P2 为扩展。核心能力受阻时保留缺项并提出替代路线，不能改标签制造完成。官方 GUI 的对照结果和主产品采用的输入实现分别记载。

任务只有在产物、相关检查和清理记录齐备后才能设为 completed。验收状态独立维护，代码写完不等于真机用例通过。依赖未完成的任务可以做只读调查，不提前宣称完成；每次只保留一个设备控制所有者。

真机输入仍需具名设备端 300 秒保护，结合新画面操作；同一编号超时查询原结果，只清理本会话流并保留 streamId 原大小写。当前续期方案尚未实现，不沿用过期控制会话。结束时确认同名保护与 Default(0)，未知结果保持待核对。

不重复索要已有设备资料和保存凭据。用户缺少真实叶片的事实继续保留；叶片和多光照实验独立推进，不阻塞通用控制开发。真实拔插或第二台电脑暂不可用时保持待验收，不用软件故障注入或同机重装替代。
