# YOLO 相机参数与眼镜资源采样

用户于 2026-11-05 要求连接现有眼镜，先采样现有 YOLO，再逐步提高相机像素和帧率，多轮测试并保存记录。

1. 原设备、原包与模型回读核验；对未修改的 1.0.0.48 先采样，作为原版参考。
2. 枚举真实 PV 相机支持的预览尺寸和帧率，保留完整能力证据。相机预览尺寸与模型输入 320 分开登记；不把放大画布或提高门户视频档位算作提高相机参数。
3. 加入仅用于本次实验的明确相机参数选择、实际参数读回与帧计数；模型权重、GPU 引擎、320 输入、阈值和 NMS 保持一致。
4. 按支持的尺寸和帧率递增，至少三个重复轮次；每轮预热、测量时间一致。固定 USB 管理和观察方式，测量期间不额外打开全息串流。
5. 保留逐次 CPU、全部 GPU 引擎、内存、模型帧计数、推理时延、驱动读回帧率、HTML 预览计数、热状态和错误。HTML 呈现计数不当作传感器全帧计数。参数不符或接口中断的尝试不记完成；低吞吐和计数停顿按原样作为性能结果保留，不为取得好结果删除或重跑。
6. 比较原配置、相同尺寸不同帧率和相同帧率不同尺寸；保存原始 JSONL、每轮统计、图表、限制和恢复证据。结束恢复原包与相机默认配置，根 README 不编辑，不发布模型或推送。

当前进展见同目录 `任务状态.json`。数据在 `reports/20261105-yolo-camera-resources/`，原始图像不作为公开交付材料。
