# 路线图

议题按产品目标推进，进度由实验结果、测试和版本说明更新。讨论与材料从对应 Issue 模板进入。

| 方向 | 需要回答的问题 | 交付材料 |
| --- | --- | --- |
| 真实叶片采集 | 叶片是否完整入框，纹理与病斑能否辨认？ | 样本批次、原图/裁剪引用、质量统计与人工观察 |
| 多光照对照 | 曝光反馈在普通光、强光、暗光与混合光下是否有效？ | 同叶片对照报告与失败案例 |
| 识别效果 | 拒识、误识和类别表现如何？ | 独立标注、数据划分及评价方案 |
| 交互与展示 | 其他控件、历史、地图与报告是否符合实际使用？ | 分项真机用例与结果 |
| 稳定性 | 网络波动、低功耗、休眠与重启后能否恢复？ | 可重复恢复用例与错误记录 |
| 资料与方法 | 有哪些相机控制、叶片分割与识别数据可复用？ | 来源清楚、适用范围明确的资料条目 |

已有非叶片链路验证不能关闭真实叶片或光照议题。新增实物实验由团队按可用样本组织，不用屏幕翻拍或离线亮度变化代替。
